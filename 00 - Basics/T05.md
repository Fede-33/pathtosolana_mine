# CONTADOR

## COMPILAR Y DESPLEGAR

### Compilar el programa:
Una vez finalizado el código, se ejecuta el comando **anchor build** para compilar el programa.

### Configurar testnet:
Lo primero que debe realizarse es configurar el cliente local de solana para que se conecte con la red testnet. Esto se realiza mediante el comando **solana config set --url https://api.testnet.solana.com**. Si no hay errores, el retorno debe ser algo parecido a:

    Config File: /home/federinux/.config/solana/cli/config.yml
    RPC URL: https://api.testnet.solana.com 
    WebSocket URL: wss://api.testnet.solana.com/ (computed)
    Keypair Path: /home/federinux/.config/solana/id.json 
    Commitment: confirmed 

### Configurar validadores:
Para esto hay dos opciones: 

* **Local Validator::** Utilizar un validador local crea una "blockchain privada", un cluster local que corre mientras que la terminal esté activa. Se ejecuta mediante el comando **solana-test-validator**

* **Configurar Anchor para testnet:** cambiar el proveedor en el archivo **Anchor.toml** 
    
        [provider]
        cluster = "localnet"
        wallet = "~/.config/solana/id.json"

    Por defecto el cluster es "localnet", debe ser cambiado por "testnet"

### Obtener SOL:
Para poder desplegar un programa se deben pagar tarifas de gas, por lo que debemos tener SOL en nuestra billetera. En testnet los SOL son gratuitos y pueden obtenerse mediante el Comando **solana airdrop 5** especificando el número de SOL que se necesita recibir. En caso de que falle el comando, se debe obtener la clave pública de la billetera, utilizando el comando **solana-keygen pubkey**, y pedir el airdrop desde la página oficial: **https://faucet.solana.com/**. Para verificar que el airdrop fue exitoso, podemos visualizar el contenido de la billetera con el comando **solana balance**

### Desplegar
Con todo lo anterior se está en condiciones de desplegar el programa en la blockchain de Solana, ejecutando el comando **anchor deploy**. Esto compilará el código del programa para la arquitectura del clúster de Solana seleccionado.Y luego subirá el binario del programa (el archivo .so en la carpeta target/deploy/) a la red de Testnet. Un retorno exitoso sería algo así:

### Confirmar despliegue

Para asegurarte de que tu programa se ha desplegado correctamente, puedes verificar el ID de tu programa y la Signature en el explorador de Solana, pegándo alguno de ellos en la barra de búsqueda de Solana Explorer **https://explorer.solana.com/**. Se debe verificar de que el selector de red en la esquina superior derecha esté en Testnet, o el cluster utilizado. Si el despliegue fue exitoso, el explorador te mostrará una página dedicada al programa con todos los detalles de la cuenta.
